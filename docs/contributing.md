# 🤝 Contributing

The contributor guide is maintained as
[`CONTRIBUTING.md`](https://github.com/augments-labs/philharmonica-adk-python/blob/main/CONTRIBUTING.md)
in the repository root. It covers environment setup, the five-check
hygiene gate, the conventions this codebase enforces, and how to open a
pull request.

For what to update in `docs/` when you ship code, see
[Maintenance](maintenance/index.md).
